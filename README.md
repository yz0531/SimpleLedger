# 简账 SimpleLedger

简账是一款面向个人使用的 Android 记账应用，默认采用“只记支出”模式，把日常记账、周期扣费、年度统计和数据备份集中在一个轻量、直观的界面中。

应用使用 Kotlin、Jetpack Compose 和 Material 3 构建，最低支持 Android 8.0（API 26）。核心记账功能完全离线；只有用户主动配置坚果云后，应用才会访问网络进行 WebDAV 备份。

当前稳定版本为 `v1.2.1`，安装包可在 [GitHub Releases](https://github.com/yz0531/SimpleLedger/releases) 下载。

## 设计特点

- 默认只记录支出，金额统一以正数展示，更符合个人消费记录习惯
- 如有需要，也可在设置中切换为“收入与支出”模式；切换回只记支出不会删除原有收入记录
- 首页只保留月份、当月花销和流水，不展示无用的笔数或平均值
- 支持全屏图片皮肤、基础纯色背景、主题颜色和图片透明度调节
- 使用紧凑的顶部区域、半透明卡片和统一图标，兼顾信息清晰度与背景表现力
- 页面切换采用轻量淡入淡出动画；首页可直接左右滑动切换月份
- 本地优先、云端可选，没有网络也能正常记账和查看统计

## 界面与交互

应用底部包含四个主要入口：`账本`、`周期`、`统计` 和 `设置`。

| 页面 | 主要内容 | 交互方式 |
| --- | --- | --- |
| 账本 | 当前年月、当月支出总额、按日期分组的账目流水 | 左右滑动切换月份；点击年月选择指定年份和月份；点击“记一笔”新增花销 |
| 周期 | 周期规则列表、启用状态、下次执行日期 | 新建、编辑、暂停、恢复或删除周期账单 |
| 统计 | 指定年份总支出、月均支出和 12 个月柱状图 | 左右滑动或点击按钮切换年份，查看每个月的花销变化 |
| 设置 | 记账模式、外观皮肤、导入导出和坚果云备份 | 所有配置均在独立页面中完成，选择后即时生效 |

### 首页

- 月份汇总卡片集中展示年月和本月支出
- 在页面上左右滑动即可切换上一个或下一个月
- 点击年月会打开年月选择器，可快速跳转到任意月份
- 流水按日期分组，点击已有账目可进入编辑或删除
- 空账本使用简洁的插图和提示，不堆叠无意义统计信息
- 底部导航栏固定布局，进入记账页时不会引起首页文字或卡片跳动

### 记一笔

- 支持金额、分类、日期和备注
- 支出分类精简为饮食、交通、购物、居住、娱乐、医疗和其他
- 只记支出模式下不显示负号，也不展示收入选项
- 收入与支出模式下可选择记录类型，并使用对应分类
- 金额输入完成后点击输入法确认键即可直接保存，无需跳转到备注
- 选择日期后立即应用并自动关闭日期选择器，无需再次确认
- 编辑过程中旋转屏幕或发生界面重建时，会尽量保留尚未保存的草稿
- 已有账目可以修改或删除

### 周期记账

支持四种自动记账频率：

- 每日：每个自然日记录一笔
- 每周：每个自然周的相同星期记录一笔
- 每两周：以开始日期为锚点，每两个自然周的相同星期记录一笔
- 每月：每个自然月的对应日期记录一笔；如果当月没有该日期，则使用当月最后一天

周期规则不是简单按固定天数累加。应用会保存自然日历锚点，并在后台或下次打开应用时补记已经到期的账目。规则可以随时暂停、恢复、编辑或删除，删除规则不会移除此前已经生成的账目。

### 年度统计

- 按年份查询支出数据
- 使用 12 个月柱状图展示全年花销趋势
- 显示全年总支出、月均支出等年度摘要
- 统计数据直接由本地数据库按年份和月份聚合，不需要加载全部历史流水

### 外观皮肤

- 支持不使用图片的基础纯色皮肤
- 提供 11 种主题颜色，可改变背景、按钮、卡片和强调色
- 提供 10 套图片皮肤：青玉、暖阳、海风、丁香、森屿、琥珀、雪岚、绯霞、夜潮和极光
- 图片透明度支持 `25%–100%` 调节，并会自动保存
- 皮肤选择页使用独立缩略图，降低同时加载多张高清图片造成的内存压力
- 支持系统深色模式，并为深色背景调整文字和蒙层对比度

## 数据导入与导出

### JSON 完整备份

JSON 备份包含账目和周期规则，适合设备迁移或完整恢复。

- 导入时按记录 ID 合并：新 ID 新增，相同 ID 使用备份内容更新
- 导入操作在数据库事务中完成，校验失败时不会只写入一部分数据
- 导入完成后会根据当前记账模式整理周期规则，并立即补记到期账目
- 单个备份文件最大 10 MB
- 单次最多处理 50,000 条账目和 10,000 条周期规则
- 数据管理页可清空本机全部账目和周期规则，执行前会显示不可撤销确认；云端和导出备份不受影响

### CSV 表格

- 导出全部账目供 Excel、Numbers 或其他表格工具查看
- 文件包含 UTF-8 BOM，减少中文在 Excel 中出现乱码的情况
- CSV 仅用于查看和分析，不作为完整恢复格式

## 坚果云备份

应用内置坚果云 WebDAV 地址 `https://dav.jianguoyun.com/dav/`，用户只需填写坚果云账号和第三方应用密码。

- 备份文件统一保存在 `/SimpleLedger/backup/`
- 支持立即手动备份、恢复最近一份云端备份
- 提供云端备份管理页，可查看、恢复或单独删除本应用生成的备份
- 管理页只识别本应用的自动/手动备份命名，目录中的其他 JSON 文件不会展示或操作
- 开启自动备份后，每次进入应用都会检查数据是否变化
- 只有账目或周期规则发生变化时才会上传新备份
- 空账本不会触发自动上传，清空本机数据后仍可使用此前的云端备份恢复
- 自动备份仅维护最近 3 份，超过后删除最早的自动备份
- 手动备份不会被自动备份的三份保留策略清理
- 恢复采用合并方式，不会删除本地独有的其他账目
- 上传成功后即记录本地数据指纹；即使旧文件暂时清理失败，也不会把本次上传误报为失败

坚果云必须使用“安全选项 → 第三方应用管理”生成的应用密码，不能直接使用网页登录密码。
应用密码默认在设置输入框中直接显示，也可通过小眼睛切换为圆点隐藏；写入本机时仍使用 Android Keystore 加密。

## 数据与隐私

- 账目、周期规则和应用设置默认保存在设备本地
- 金额以人民币“分”为单位使用整数存储，避免浮点计算误差
- 坚果云应用密码通过 Android Keystore 加密后保存
- 设备迁移不会复制无法在新设备解密的坚果云凭据
- Android 系统云备份不会包含账本数据库、共享配置或导出文件
- Git 仓库不包含用户账号、应用密码、签名文件、本机 SDK 配置、数据库或测试导出数据

## 使用 Android Studio 构建

1. 安装 Android Studio，并在 SDK Manager 中安装 Android SDK 35。
2. 使用 Android Studio 打开项目目录。
3. 将 Gradle JDK 设置为 JDK 21；最低可使用 JDK 17，暂不建议使用 JDK 24 或更高版本。
4. 等待 Gradle Sync 完成。
5. 连接 Android 8.0 以上设备或创建模拟器，然后运行 `app` 配置。

命令行构建调试 APK：

```bash
./gradlew assembleDebug
```

运行单元测试和 Lint：

```bash
./gradlew testDebugUnitTest lintDebug
```

调试 APK 会生成在 `app/build/outputs/apk/debug/app-debug.apk`。

正式 APK 使用本地 `keystore.properties` 中配置的私有签名生成。签名文件与配置已被 Git 忽略，不会上传到公开仓库。
